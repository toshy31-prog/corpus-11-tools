# Rapport quotidien — 2026-08-18

## Changement substantiel

La branche d'orientation compositionnelle a été close à l'ordre 3 après P1/P2/H3 et autopsie minimale de l'associateur. Le budget est ensuite passé à factorisation, où le reste d'ordre trois s'est transporté vers `S4` mais la stabilité sous quatrième factorisation a échoué. La priorité a enfin été déplacée vers récupération/désinscription avec une réplication prospective asynchrone multi-port.

## Orientation compositionnelle — fermeture

Résultats gelés :

- P1 : `too_common` — `1690/3192 = 52,94 %` de classes chirales fortement couplables ;
- P2 : `not_transported` / `no_predictive_transport` ;
- H3 : `standard_absorption` ;
- autopsie : `I2 + A2` est le premier raffinement testé suffisant, avec zéro résidu P1/P2/joint.

La voie P1/P2 est close à l'ordre 3. Aucun P3 adaptatif.

## Factorisation — transport puis H4 négatif

Le test prospectif sur les 24 matrices de permutation ordinaires de `S4` sur `Q^4` a trouvé une clé `(3,3,3)/(2,2,2)` avec dimension triple `1` pour 16 triplets et `2` pour 4 triplets : `transported_remainder`.

L'ajout prospectif d'une quatrième factorisation a ensuite produit 420 extensions, quatre strates géométriques appariées et des contrastes `Delta_D4` : un positif, trois nuls, médiane `0`. Décision : `not_supported`.

Toutes les matrices de permutation fixent `span((1,1,1,1))`. Les triplets `D3=1` sont déjà au plancher commun et les `D3=2` perdent leur dimension supplémentaire sous les ajouts non triviaux appariés. La stabilité objectale prospective n'est donc pas établie.

## Récupération / désinscription — réplication asynchrone multi-port

### Discipline de réplication

Un petit cas `n=5` a servi uniquement à la conception. Il n'est pas compté comme confirmation. Une famille distincte `n=6` a été gelée avant ouverture : cinq nœuds internes en DAG ordonné, cinq arêtes source possibles et dix arêtes internes possibles, soit `32768` architectures brutes.

### Dynamique

État initial : les six nœuds portent la trace `1`.

Un ensemble de ports est clampé à `0`. Un nœud interne non clampé met à jour son état par le OR de ses prédécesseurs.

Deux régimes sont séparés :

- `C_erase_inf` : relaxation asynchrone répétée jusqu'à convergence sous ordonnance équitable ;
- `C_erase_1` : une seule activation de chaque nœud interne, dans un ordre adversarial.

`C_info=1` pour toute la famille.

### Résultats exacts

- `32768` architectures brutes ;
- `9765` architectures atteignables depuis la source ;
- `C_info=1` partout ;
- `C_erase_inf=1` partout ;
- `685` strates selon les contrôles gelés ;
- **176 strates appariées** contiennent plusieurs valeurs de `C_erase_1` ;
- zéro violation sur toute la population de l'identité `C_erase_1 = 1 + tau(G_int)` où `tau` est la couverture minimale de sommets du graphe interne non orienté.

Distribution :

- `C_erase_1=1` : 1 architecture ;
- `2` : 276 ;
- `3` : 4824 ;
- `4` : 4648 ;
- `5` : 16.

Décision H1 : **`replicated_profile_separation`**.

Classification scientifique : **`standard_profile_separation`**.

### Exemple apparié

Deux architectures ont mêmes degré source `4`, nombre d'arêtes internes `2`, multiensembles de degrés internes `(0,0,0,1,1)`, distances source `(1,1,1,1,2)`, SCC singleton, aucun cycle et `C_erase_inf=1`, mais :

- architecture A : `C_erase_1=2` ;
- architecture B : `C_erase_1=3`.

La différence est exactement `tau=1` contre `tau=2`.

### Lecture bornée

Le résultat renforce l'énoncé opérationnel faible : récupération, effacement à convergence et effacement sous deadline/passe bornée sont des axes distincts de ressources.

Il ne fournit toujours pas de nouvelle mesure fondamentale : le nouvel axe une-passe est exactement une couverture minimale de sommets dans cette famille.

## Prochaine allocation

**Priorité immédiate : transport matériel ou quasi-matériel du profil récupération/désinscription.**

Ne pas agrandir encore le catalogue de DAGs. Le prochain protocole doit introduire des latences, pertes ou ordres de mise à jour mesurés, avec avant acquisition :

- ports de lecture et de reset ;
- deadline ;
- règle de convergence ;
- taux de trace résiduelle ;
- détectabilité ;
- coût en messages, opérations et temps.

Un banc d'émulation réseau ou de processus asynchrones reproductible est acceptable comme étape intermédiaire ; toute portée matérielle ou physique restera inconnue tant qu'aucun dispositif réel n'est mesuré.
