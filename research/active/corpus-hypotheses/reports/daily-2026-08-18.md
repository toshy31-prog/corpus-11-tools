# Rapport quotidien — 2026-08-18

## Changement substantiel

La branche d'orientation compositionnelle a subi trois tests successifs sur la population complète des magmas d'ordre 3 : rareté de la réponse forte (P1), transport hors protocole (P2), puis audit de décomposition statique (H3). Les trois tests étaient gelés avant ouverture de leurs sorties respectives.

## P1 — couplage par termes miroir

Préenregistrés avant résultat : quotient par isomorphisme, opposition, grammaire statique, `d_chi`, `A_chi`, six covariables, arbres binaires complets à 3/4/5 feuilles, indice de collision, seuil `1/27` et fenêtre confirmatoire `1–25 %`.

Observations exactes :

- `19 683` tables étiquetées ;
- `3 330` classes d'isomorphisme ;
- `3 192` classes chirales ;
- `1 690 / 3 192 = 52,94 %` fortement couplables ;
- `42` strates appariées sur les résumés statiques initiaux mais séparées sur le statut fort/faible ;
- `2506` réponses dès 3 feuilles, `274` supplémentaires à 4, `50` supplémentaires à 5, `362` nulles jusqu'à 5.

Décision : **`too_common`**. La prédiction de rareté est renversée.

## P2 — transport vers une sonde indépendante

Avant ouverture de P2, les 42 strates et leur partition P1 ont été gelées. La seconde sonde n'utilise ni arbres miroir, ni parenthésages, ni indice de collision : elle compare les distributions de rang de chaînes de translations gauche/droite aux horizons 2/3/4.

Observations exactes :

- `2 942 / 3 192` classes chirales ont une réponse P2 non nulle ;
- 292 profils P2 distincts ;
- sur les 42 strates : 14 contrastes positifs, 11 nuls, 17 négatifs ;
- médiane du contraste : `0` ;
- prédiction gelée depuis P1 : 11 succès, 14 égalités, 17 échecs.

Décision : **`not_transported`** et **`no_predictive_transport`**.

La seconde sonde n'est pas inerte, mais l'organisation fort/faible de P1 ne se transporte pas vers elle.

## H3 — décomposition statique P1/P2

Avant calcul, une hiérarchie cumulative d'invariants statiques a été gelée :

- `I0` : résumés historiques ;
- `I1` : types de conjugaison des translations élémentaires ;
- `I2` : signatures standards des semigroupes de translations ;
- `I3` : signature statique de l'associateur ;
- `I4` : tables canonisées de petits termes, niveau riche de dernier recours.

Résidus exacts (`R_k` = cellules statiquement identiques mais dynamiquement séparées) :

- `I0` : P1 `156`, P2 `148` ;
- `I1` : P1 `19`, P2 `14` ;
- `I2` : P1 `7`, P2 `2` ;
- `I3` : P1 `0`, P2 `0`, profil conjoint `0` ;
- `I4` : toujours `0`.

Décision préenregistrée : **`standard_absorption`**.

Le niveau `I3` forme `1 590` cellules pour `1 596` paires de classes opposées : il ne reconstruit donc pas simplement chaque magma modulo opposition. Les quelques collisions restantes partagent néanmoins exactement les mêmes profils P1/P2.

## Décision scientifique

### Orientation compositionnelle

Statut : **`weakened`**.

Trois conclusions sont maintenant gelées :

1. la réponse forte de P1 n'est pas rare (`too_common`) ;
2. la partition P1 ne se transporte pas vers P2 (`not_transported`) ;
3. P1 et P2 sont entièrement déterminés, à l'ordre 3, par une hiérarchie statique arrêtée à l'associateur (`standard_absorption`).

La voie P1/P2 ne fournit donc aucun résidu exact justifiant un nouvel invariant intrinsèque de couplabilité. Les 42 strates initiales reflétaient l'insuffisance de la première batterie statique, pas la démonstration d'un canal dynamique profond.

Non établis : orientation macroscopique, amplification collective, canal matériel, émergence du temps, généralité au-delà de l'ordre 3.

## Autres hypothèses

Aucun statut n'est modifié aujourd'hui pour récupération/désinscription, frustration temporelle, invariants de factorisation, complexe de distinctions compatibles ou holonomie `S3`.

## Prochaine action

Ne pas lancer P3.

Une ablation **exploratoire uniquement** des composantes de `I3` peut préciser quelle information de l'associateur absorbe les sept dernières cellules de P1 et les deux de P2. Elle ne pourra pas reclasser H3.

Toute nouvelle expérience dynamique ou réplication d'ordre 4 doit être motivée par une prédiction indépendante, non par la recherche adaptative d'un signal survivant aux trois résultats négatifs ci-dessus.
