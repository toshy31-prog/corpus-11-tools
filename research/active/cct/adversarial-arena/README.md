# Arène adverse CCT v1

Cette campagne met une interprétation exécutable étroite du noyau constitutionnel CCT face à trois rivaux dans six mondes **internes et fictifs** : monopole de dépendance, capture d'urgence, cascade de fragmentation, contournement écologique, domination locale et siège informationnel.

Elle cherche volontairement des conditions de perte : franchissement d'un seuil non compensable (besoins vitaux, écologie, droits, pouvoir non contrôlé, sortie, récupération) ou rival non inférieur sur tout le vecteur. Les identités sont séparées du rapport public afin de permettre une revue aveugle.

Exécuter :

```bash
node run_campaign.mjs
node --test test_campaign.mjs
```

Les sorties restent `internal_synthetic`. Elles peuvent justifier une révision de la logique codée ou une nouvelle campagne ; elles n'établissent ni faisabilité territoriale ni effet politique réel.

Le premier passage et les candidats de correction qu'il motive sont consignés dans [`revision-register.md`](revision-register.md). Les corrections ne sont pas rejouées sur les mêmes mondes pour être déclarées meilleures.
