# CCT-EXEC 6.7 — admission contestable des observateurs (candidate)

La rotation conjointe 6.6 peut être techniquement sûre tout en laissant le registre sortant organiser seul sa reproduction. Cette candidate ajoute un registre séparé de trois sélecteurs et exige deux approbations signées, issues de contrôleurs et domaines distincts de ceux des observateurs. Les approbations engagent le registre proposé, une voie d'appel et une échéance de mandat bornée.

La confrontation tenue à l'écart conserve une rotation valide sous 6.6, mais place les sélecteurs sous le contrôle d'un observateur : 6.7 refuse l'admission. Le protocole ne prouve pas la légitimité du registre de sélection, la réalité des conflits d'intérêts ni l'utilisabilité de l'appel.

```bash
node --test test.mjs
node held-out/run-confrontation.mjs
```
