# CCT-EXEC 8.7 — contestation prospective d'une arête omise (candidate)

La 8.6 détecte les convergences présentes dans son graphe, mais pas une arête absente. La 8.7 admet une contestation documentée par deux réviseurs indépendants et lie l'arête à ajouter à une campagne strictement future, avant l'ouverture de ses observations d'issue. Elle ne réécrit pas après coup la conclusion de la campagne courante.

La confrontation tenue à l'écart tente une insertion rétroactive après connaissance du résultat. Elle est refusée. L'admission synthétique établit une obligation de révision future, non la vérité matérielle de l'arête.

```bash
node --test test.mjs
node held-out/run-confrontation.mjs
```
