# CCT-EXEC 1.6 candidate — continuité durant l'attente de preuve

Quand 1.5 retient une clôture faute de provenance suffisante, 1.6 refuse qu'une
action d'attente protège seulement le vital et l'écologie tout en laissant une
dette ouverte se détériorer. Toute continuation doit protéger chacun des axes
portés par les dettes ouvertes.

Ce mécanisme peut aussi échouer honnêtement : sans action qui protège toutes les
dettes, il renvoie `CCT_EVIDENCE_HOLD_DEBT_PROTECTION_INFEASIBLE` plutôt que de
masquer le coût de l'attente.
