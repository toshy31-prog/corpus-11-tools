# CCT-POL 1.1 — contrat vérifiable de doctrine

Ce dossier compile une partie bornée de `../CCT-POL-1.1-apports-2026-09-04.md`
en conditions structurelles. Il ne mesure pas une institution réelle et ne rend
pas la doctrine vraie par exécution locale.

Il vérifie seulement qu'un candidat politique ne peut pas se dire CCT-POL 1.1
en supprimant silencieusement le contre-champ, la preuve non identitaire, la
frontière de démarchandisation, les marges distribuées, la protection des
amortisseurs écologiques ou les données agrégées de traitement.

```bash
node validate.mjs
node --test test.mjs
```

Le statut maximal est `written_and_statically_validated`. Une prochaine étape
exige une arène gelée et des comparateurs appariés : crise climatique,
reconcentration économique, discrimination administrative et rupture
logistique, avec des résultats non compensables.

Le pré-enregistrement de cette arène est désormais dans [`arena/`](arena/).
Ses mondes sont internes et ne peuvent donc servir qu'au développement négatif.
