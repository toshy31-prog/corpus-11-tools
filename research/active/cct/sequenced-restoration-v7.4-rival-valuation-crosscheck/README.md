# CCT-EXEC 7.4 — contre-mesure rivale de la valorisation (candidate)

La 7.3 empêchait le changement opportuniste de méthode sans établir que son proxy suivait la perte. La 7.4 exige deux mesures signées issues de contrôleurs, domaines, canaux et lignées techniques distincts. Les dépendances communes doivent être déclarées dans la signature : une convention bénigne peut être partagée, mais tout mode de panne commun matériel interdit de compter deux appuis. Pour chaque axe, leur écart doit rester sous la tolérance préengagée ; au-delà, la valorisation est rouverte au lieu d'être moyennée ou absorbée.

La confrontation tenue à l'écart oppose une mesure directe à une référence appariée qui divisent la perte par deux : la clôture est refusée. Le test discrimine un désaccord synthétique ; il ne valide aucun des deux construits dans le monde réel.
