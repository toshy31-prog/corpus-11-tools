# CCT-EXEC 8.8 — report obligatoire d'une arête admise (candidate)

La 8.7 créait une obligation de révision future sans vérifier son exécution. La 8.8 refuse la campagne suivante tant que son manifeste de lignée, scellé par deux gardiens indépendants avant les issues, n'inclut pas le digest exact de l'arête admise.

La confrontation tenue à l'écart fournit une campagne au bon numéro mais omet l'arête. Elle est refusée. La couche établit une barrière d'admission synthétique ; elle ne prouve pas que le manifeste scellé a été exécuté sur le terrain.

```bash
node --test test.mjs
node held-out/run-confrontation.mjs
```
