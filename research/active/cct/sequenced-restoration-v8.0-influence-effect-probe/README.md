# CCT-EXEC 8.0 — sonde d'effet des influences (candidate)

La 7.9 assimilait toute convergence amont à une coordination. La 8.0 exige deux sondes de retrait indépendantes et appariées. Le quorum de contestation ne perd son veto que si le retrait de l'influence commune modifie la décision observée dans les deux sondes. Un effet absent ou des sondes divergentes ne permettent plus d'inférer une coordination.

La confrontation tenue à l'écart partage une infrastructure amont sans changement décisionnel après retrait. Les fixtures éprouvent ce discriminant local ; elles n'identifient pas un effet causal général hors du protocole apparié.

```bash
node --test test.mjs
node held-out/run-confrontation.mjs
```
