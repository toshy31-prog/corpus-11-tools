# CCT 5.5 candidate — axis-calibration transport

Candidate 5.4 supports axis labels only in its calibration scope. This candidate forbids silently extending that conclusion to a different population, protocol, or environment.

It requires at least two distinct target contexts, an explicit source/target difference profile, bridge evidence, target reference re-observation, class-wise Wilson bounds, and a target-specific reversal condition. A held-out case preserves perfect source calibration while one target context fails specificity; transport is rejected rather than averaged across contexts.

This local synthetic candidate supports only the tested target profiles. It does not establish untested-context transport, causal relevance, authorization, deployment, or external robustness.
