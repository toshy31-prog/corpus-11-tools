# Benchmark contrastif v1

Jeu synthétique gelé avant l'évaluation de `ContrastiveDoctrineRouter v1`. Il
est distinct des paires de passages produit et interdit à l'entraînement ou au
réglage. Il vérifie des requêtes de doctrine formulées comme scènes utilisateur,
dont un cas négatif. Il reste une évaluation interne écrite dans le projet.
