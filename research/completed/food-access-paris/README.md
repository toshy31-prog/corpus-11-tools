Ce dossier conserve un protocole qui cherchait à organiser des réparations petites, réelles, vérifiables et cumulables. Le mot « intervention » désigne ici le nom historique d’un cycle de recherche ; il ne signifie pas qu’une intervention de terrain a effectivement eu lieu.

## Mission

Réduire un dommage évitable concret par cycle, sans confondre préparation, activité et effet.

Le protocole prévoyait qu’une intervention ne compterait que si :

- un besoin réel a été exprimé par les personnes concernées ou une organisation qui agit avec elles ;
- une ressource, une capacité, un accès ou un recours utilisable a effectivement changé ;
- le coût, les bénéficiaires, les limites et les suites sont consignés ;
- les personnes concernées peuvent refuser, corriger ou interrompre l’intervention.

## Cycle

1. Recevoir un besoin plutôt que l’inventer.
2. Vérifier l’urgence, le dommage, les acteurs déjà présents et ce qui manque réellement.
3. Choisir la plus petite action susceptible de modifier la situation.
4. Exécuter.
5. Demander si l’aide a été utile.
6. Réparer, transmettre ou arrêter.

La recherche est subordonnée à une décision ou à une action nommée. Une note qui ne peut rien changer s’arrête.
