This skill is an invocation wrapper for `CAP.PROTOCOL_ROBUSTNESS`. The capability node describes a possible behavior under conditions; it is not itself an algorithm and its presence does not establish robustness.

1. Preserve the user's scene, terminology, and requested level of conclusion.
2. Read `references/capability.md` before applying this capability.
3. Load critical dependencies listed in that reference. Load contextual dependencies only when the scene makes them material.
4. Use the source-derived RULE / PROCEDURE / SCHEMA material in the reference according to its primitive type:
   - RULE: conditional consequence, never a free-standing sequence.
   - CAPABILITY: possible behavior under conditions, never an algorithm.
   - PROCEDURE: ordered/stateful transformation path, without autonomous semantic judgment.
   - SCHEMA: admissible object shape, without semantic decision.
5. Separate observation from attribution, correlation from causality, and absence of trace from absence of phenomenon unless detectability is established.
6. State the strongest sufficiently supported conclusion; localize uncertainty that can actually reverse it.
7. Stop when more material cannot change conclusion, attribution, confidence, protection, recourse, capacity, trajectory, form, or reversal.
