---
name: rival-model-discrimination
description: Compare serious rival hypotheses, mechanisms, predictors, or models through matched predictions and discriminating outcomes. Use when several explanations fit, a baseline is missing, a novelty claim needs comparison, or a test must distinguish rather than merely confirm.
---

Treat this skill as an invocation wrapper for the design candidate in `references/capability.md`; a comparison schema does not create a decisive result.

1. Preserve the user's candidates; when material rivals are missing, generate them independently before loading audit criteria.
2. Read `references/capability.md` completely.
3. Load the critical dependencies named there and contextual dependencies only when they change the comparison.
4. Freeze candidates, information budgets, predictions, outcomes, and failure conditions before reading the discriminating result when possible.
5. Report `discriminates`, `compatible_survivors`, `inconclusive`, or `candidate_set_incomplete`.
6. Do not manufacture a unique winner from shared fit, unmatched flexibility, or a post hoc baseline.
