# Command Effect Verification

Preserve each link: request, recommendation, authorization, command, receipt, execution, effect, verification, interruption. Do not infer a later link from an earlier one.

## Workflow

1. Name the requested effect and its scope.
2. Identify the actor authorized and materially able to act.
3. Trace transmission and receipt separately.
4. Establish execution from a material trace.
5. Verify the effect with an independent observable where possible.
6. Name interruption, rollback, and the first unverified link.

Return the strongest established link, the missing link, bounded attribution, and the evidence that would change the conclusion. Read `references/capability.md` for provenance and graph relations.
