# Relation Loss Assessment

Inventory objects and relations separately.

## Workflow

1. Name the objects that remain.
2. Map required relations and their carriers.
3. Test access, order, synchronization, transmission, and reconnection.
4. Identify which future actions disappeared despite object survival.
5. State the consequential remainder and a repair test.

Read `references/capability.md` for provenance and graph relations.
