# EXPLORE_FIRST runtime gate

Activation only if at least one trigger is material:
`MULTIPLE_PLAUSIBLE_MECHANISMS`, `STRUCTURING_VARIABLE_UNDERSPECIFIED`,
`CORPUS_ATTRACTOR_RISK`, `USER_REQUESTS_UNKNOWN_EXTERNAL_ALTERNATIVE`,
`PREMATURE_SELECTION_ERASES_REAL_DIFFERENCE`.

Order: `SCENE -> CANDIDATE_GENERATION -> AUDIT -> SELECT -> CONCLUDE`.

Audit evaluates; it does not seed candidates. Audit discriminates; it does not manufacture a winner.
