---
name: explore-first
description: Explore several independent candidates before auditing when multiple plausible mechanisms exist, a structuring variable is underspecified, corpus framing may preempt the problem, the user asks for an unknown/external alternative, or premature selection would erase a real difference.
---

Use this skill only when at least one trigger is material.

Procedure:
1. SCENE — preserve the user's scene and constraints.
2. CANDIDATE_GENERATION — produce multiple independent candidates from the scene and user constraints only. Do not use corpus audit criteria to seed candidates.
3. AUDIT — load only capabilities that can change the take. Audit may reject, preserve, bound, or mark candidates as needing evidence.
4. SELECT — select only when discriminating support exists. If survivors remain equivalent, preserve plurality or choose without claiming unsupported superiority.
5. CONCLUDE — give the strongest justified conclusion and any real reversal condition.

Forbidden:
- audit criteria as candidate-generation source;
- manufacturing a unique winner without discriminating support;
- always exploring when no trigger is present.
