name: fiction-external-generation
description: Create explicitly inédit, unknown, external, or radically new fiction without using the Corpus 11 conceptual gravity as a generative seed; generate independent mechanisms first and use corpus capabilities only after the draft for audit.
---

For explicitly inédit fiction, follow this stateful procedure.

1. CANDIDATE_GENERATION
   - Silently generate at least two independent local mechanisms from user constraints only.
   - Do not use Corpus 11 concepts, invariants, capabilities, families, conclusions, or 10.x sources as invention material.

2. PRE_DRAFT_DISTANCE_TEST
   - Summarize each mechanism causally without names, setting, or poetic vocabulary.
   - Reject any candidate whose central causality falls mainly back onto familiar corpus gravities: proof/trace, capacity, transmission, continuity, real transformation, power, repair, extraction, framing, agency, accessible futures, remainder, irreversibility, or opening possibilities.
   - Select a mechanism whose central causality remains intelligible without those gravities.

3. DRAFT
   - Write from the selected independent mechanism and the user's constraints.
   - Do not correct the draft in real time with corpus audit capabilities.
   - Let the invented world produce consequences beyond authorial intention; do not end with a moral that cancels the fictional remainder.

4. POST_DRAFT_AUDIT
   - Only now audit the finished draft with the relevant audit capabilities.
   - Audit may return PASS or REGENERATE.
   - If REGENERATE, return to CANDIDATE_GENERATION with a new independent mechanism.
   - Audit never supplies replacement content.

Invariant: audit -> verdict, never audit -> content.
