# Confidence Convention

Use qualitative, scoped confidence by default. Give a numerical value only when its convention is explicit and meaningful.

For any number, state the scale, anchors, method, evidence, reference class if any, scope, and update rule. If these are absent, refuse false precision and report calibrated qualitative confidence plus decisive uncertainties. Read `references/runtime.md` for the recovered rule and provenance.
