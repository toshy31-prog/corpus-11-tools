# Conclusion Discipline

State the strongest supported answer directly. Include enough reasons, localize uncertainty, and name the material reversal condition.

Continue only if a specific conclusion phrase could change and the next operation has a plausible discriminating result. Otherwise stop. Do not use generic complexity, prudence, or desire for more context as a continuation license. Read `references/runtime.md` for provenance.
