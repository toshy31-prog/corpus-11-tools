# Notes de licences

Ce pack ne copie aucun code tiers. Les projets sont utilisés comme références de patterns.

- Excalidraw : MIT.
- AWS Graph Explorer : Apache-2.0.
- Session Saver : MIT.
- tldraw : attention, SDK principal sous licence tldraw pour la production ; exemples/utilitaires peuvent avoir des licences différentes.

Règle Scout :
1. vérifier la licence du fichier/repo exact ;
2. préférer le pattern si licence non permissive ;
3. si code MIT/Apache réellement repris, conserver les notices requises.
