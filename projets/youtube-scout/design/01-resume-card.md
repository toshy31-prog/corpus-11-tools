# UX future : carte de reprise explicite

```text
Fouille précédente disponible
Kosh — Black Noise [MTRON009]
Dernière activité : 13 sept. 2026

[Reprendre]   [Ignorer]
```

Règles :
- jamais de reprise automatique ;
- pas de modal ;
- Ignorer n'efface pas le graphe ;
- Reprendre est une action explicite ;
- éventuellement "Supprimer cette reprise" séparé et confirmé.
