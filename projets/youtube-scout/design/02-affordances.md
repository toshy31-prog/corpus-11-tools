# Affordances UI — backlog

## Problème
Plusieurs surfaces ont une apparence proche :
- carte info,
- bouton,
- accordéon,
- filtre,
- direction,
- élément sélectionnable.

## Recommandations
- chevron standard pour accordéons ;
- `cursor:pointer` uniquement sur interactif ;
- hover plus visible ;
- `:focus-visible` net ;
- état actif des directions plus contrasté ;
- `aria-expanded` sur accordéons ;
- bouton primaire distinct des cartes de statut.

## À ne pas faire
- trop de couleurs sémantiques ;
- animation partout ;
- transformer Scout en dashboard SaaS générique.
